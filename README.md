# Resonix Studio

Цифровая музыкальная рабочая станция (DAW) в браузере, с рабочими процессами в духе FL Studio: Channel Rack со степ-секвенсором, Piano Roll, Playlist, Mixer с эффектами, автоматизация, запись и экспорт. Самостоятельный продукт: название, интерфейс и код оригинальные.

Стек: React 19, TypeScript, Vite, Web Audio API (AudioWorklet, OfflineAudioContext), IndexedDB, Canvas и SVG. Из внешних зависимостей во время работы есть только `react`, `react-dom`, `immer` и плагины Capacitor для Android-версии.

## Запуск

```bash
npm install
npm run dev        # дев-сервер
npm run build      # проверка типов и сборка в dist/
npm test           # юнит-тесты (vitest)
```

Сборка статическая (`base: './'`), поэтому `dist/` можно выложить на любой хостинг.

`npm run build:artifact` собирает одну самодостаточную HTML-страницу (`dist/resonix-artifact.html`) для публикации как артефакт claude.ai. Там файлы сохраняются через диалог хоста, а форматы, которые хост не принимает напрямую (WAV, MIDI, `.resonix`), упаковываются в `.zip`. Импорт проекта принимает и такой `.zip`. Микрофон и Web MIDI в артефакте недоступны: их блокирует песочница хоста. Для записи звука и MIDI-клавиатуры нужен обычный запуск (`npm run dev` или свой хостинг).

## Android-приложение (APK)

Папка `android/` содержит Android-проект на [Capacitor](https://capacitorjs.com): та же студия во встроенном WebView, плюс нативное сохранение файлов, аппаратная кнопка «Назад», запрос доступа к микрофону и автосохранение при сворачивании.

**Готовый APK** собирает GitHub Actions (`.github/workflows/android.yml`) на каждый push и выкладывает в релиз `apk-latest`:
`https://github.com/<владелец>/<репозиторий>/releases/download/apk-latest/resonix-studio.apk`.
Скачайте файл на телефон и откройте его. Android попросит разрешить установку из этого источника.

Особенности приложения:
- Экспорт WAV, MIDI, стемов и проекта сохраняется в «Документы/ResonixStudio». Если общее хранилище недоступно, открывается меню «Поделиться».
- Запись с микрофона работает, Android спросит разрешение при первой записи. Web MIDI во встроенном WebView Android недоступен.
- Проекты хранятся внутри приложения (IndexedDB) и переживают обновления, потому что все сборки подписаны одним ключом `android/app/resonix-sideload.keystore`. Этот ключ публичный и годится только для установки вручную. Для Google Play нужен собственный закрытый ключ.

Собрать самому (нужны Android SDK и JDK 21):

```bash
npm run build && npx cap sync android
cd android && ./gradlew assembleRelease   # app/build/outputs/apk/release/app-release.apk
```

## Возможности

**Транспорт.** Play/Pause/Stop, режимы паттерна (PAT) и песни (SONG), цикл (вся песня или регион, заданный на линейке Playlist), метроном с акцентом на сильную долю, темп от 20 до 999 BPM (тянуть мышью или ввести двойным кликом), размеры такта 2/4–12/8, индикатор позиции «такт:доля:шаг» и времени.

**Channel Rack.** Степ-секвенсор на 1–16 тактов, рисование шагов протягиванием, velocity колесом мыши, свинг. У каждого канала mute, громкость, панорама и выбор канала микшера. Если ноты канала не лежат на сетке шагов, в строке показывается мини-пианоролл. Меню канала: клонирование, перемещение, заливка каждого N-го шага, очистка, удаление.

**Piano Roll.** Рисование, выделение рамкой, ластик, прокрутка. Ноты двигаются и меняют длину; Ctrl+перетаскивание копирует. Привязка от 1/64 до такта, включая триоли. Рисование аккордами, «призрачные» ноты других каналов, лейн velocity. Копировать/вставить/дублировать, квантизация, легато, транспонирование. Клавиатура слева проигрывает ноты. На тач-экранах прокрутка двумя пальцами.

**Playlist.** 12 дорожек и больше, клипы трёх типов: паттерн, аудио, автоматизация. Кисть ставит выбранный паттерн или сэмпл. Клипы перемещаются между дорожками, обрезаются с обоих краёв (у аудио с учётом смещения в файле), нарезаются, дублируются. Можно выделять рамкой и перетаскивать паттерны и сэмплы из браузера или аудиофайлы прямо из системы. Аудиоклипы показывают волну. Mute дорожек, регион цикла, плейхед следует за воспроизведением.

**Инструменты.**
- Субтрактивный синтезатор: 2 осциллятора и саб, фильтр LP/HP/BP с огибающей, ADSR, LFO на срез или высоту, моно-режим с глайдом. Шесть пресетов.
- Драм-синтезатор: kick, snare, clap, closed/open hat, tom, rim, crash, cowbell, 808. Параметры: подстройка, затухание, тон, панч. Группы глушения (открытый хэт глушится закрытым) и следование высоте ноты.
- Сэмплер: корневая нота, точная подстройка, старт, реверс, луп, one-shot, ADSR, фильтр.

**Mixer.** Мастер и 16 инсертов: фейдер с аудиокривой, панорама, mute/solo, стерео-индикаторы пиков с удержанием, до 10 эффектов на канал (bypass, порядок, удаление).

**Эффекты.** Parametric EQ (3 полосы), Filter, Compressor, Limiter, Delay (синхронизация с темпом, пинг-понг, тон в петле обратной связи), Reverb (генерируемый импульс, размер, демпфирование, предзадержка, low cut), Distortion (soft/hard/wavefold), Chorus, Lo-Fi Crusher.

**Автоматизация.** Правый клик (или долгое нажатие) по любой автоматизируемой ручке → «Создать клип автоматизации», как в FL. Автоматизировать можно громкость и панораму каналов и микшера, параметры инструментов и эффектов. Редактор точек с привязкой к сетке и готовыми формами: подъём, спад, синус, треугольник, пила.

**Запись.**
- Ноты: с клавиатуры компьютера (режим пианино, ряды Z–M и Q–U) или с MIDI-клавиатуры (Web MIDI) в текущий паттерн.
- Звук: с микрофона или линейного входа через AudioWorklet с компенсацией задержки. Дубль становится аудиоклипом в Playlist.

**Проекты.** Автосохранение в IndexedDB, список проектов, «Сохранить как», переименование. Файл проекта `.resonix` переносит проект вместе с пользовательскими сэмплами. Импорт аудио (WAV, MP3, OGG, FLAC, M4A — всё, что декодирует браузер) и MIDI.

**Экспорт.** WAV 16/24/32-float, 44.1/48/96 кГц, песня или паттерн, хвост для эффектов, нормализация, стемы (WAV на каждый канал микшера в одном `.zip`). Экспорт MIDI паттерна или всей песни.

**Undo/Redo.** История на 200 шагов; одно движение ручки или ноты — один шаг.

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| Space | Play / Stop |
| F5 / F6 / F7 / F9 | Playlist / Channel Rack / Piano Roll / Mixer |
| F8 | Браузер |
| L | Переключить PAT / SONG |
| R | Включить запись |
| P / E / D | Инструмент: рисование / выделение / ластик |
| Ctrl+Z, Ctrl+Y | Отмена / повтор |
| Ctrl+S | Сохранить |
| Ctrl+R | Экспорт аудио |
| Ctrl+A / C / X / V / B | Выделить всё / копировать / вырезать / вставить / дублировать |
| ↑ ↓ (Shift) | Транспонировать на полутон (октаву) |
| Q | Квантизация (Piano Roll) |
| Delete | Удалить выделенное |
| Ctrl+колесо | Масштаб по времени |
| Esc | Закрыть верхнее окно |

Мышь: двойной клик по ручке сбрасывает её; Shift при перетаскивании даёт точную настройку; Alt при перетаскивании нот и клипов отключает привязку. Правый клик по клипу удаляет его, как в FL, а Shift+правый клик открывает меню.

## Архитектура

Музыкальные данные отделены от интерфейса. Проект хранится как неизменяемое дерево (immer), а движок сравнивает версии и пересобирает только то, что изменилось.

```
src/
  core/        модель данных, время и тики, спецификации параметров, хранилище с undo/redo
  audio/
    events.ts      чистый сбор событий (ноты, аудио, автоматизация) для диапазона тиков
    sequencer.ts   планирование событий в граф; общий для реального времени и экспорта
    graph.ts       каналы → инсерты микшера → цепочки эффектов → мастер
    engine.ts      AudioContext, транспорт (lookahead по таймеру воркера), метроном, запись, MIDI, индикаторы
    render.ts      офлайн-рендер (OfflineAudioContext), стемы, нормализация
    instruments/   синтезатор, драм-синт, сэмплер, огибающие
    effects/       9 эффектов на нативных узлах Web Audio
    recorder.ts    захват входа через AudioWorklet с выравниванием по транспорту
    samples.ts     банк сэмплов и встроенная библиотека, рендерится при запуске
    wav.ts         WAV-кодер, пики для волн
  project/     фабрики и демо, IndexedDB, файлы проекта, MIDI (SMF), zip
  platform/    оболочка Android-приложения: сохранение файлов, кнопка «Назад», жизненный цикл
  state/       хранилища приложения, действия редактирования, жизненный цикл проекта
  ui/          панели (TopBar, Browser, ChannelRack, PianoRoll, Playlist, Mixer, окна) и компоненты
```

Детали, на которых держится тайминг и звук:
- Тики: 96 PPQ; шаг 1/16 = 24 тика. Всё позиционирование музыкальное, секунды считаются в момент планирования, поэтому смена темпа во время воспроизведения работает.
- Планировщик смотрит на 120 мс вперёд и обходит время шагами по 1/16. Тики таймера идут из Web Worker, чтобы не тормозить в фоновой вкладке. Если воркер заблокирован, срабатывает сторожевой таймер и откат на `setInterval`.
- Срез фильтра синтезатора и сэмплера — это `ConstantSourceNode`, подключённый к `detune` фильтров всех голосов. Поэтому автоматизация среза плавно действует и на уже звучащие ноты.
- Mix у эффектов управляется одним `ConstantSourceNode` на оба плеча (dry/wet), так что он автоматизируется одной кривой.
- Экспорт строит тот же граф на `OfflineAudioContext` и прогоняет тот же секвенсор, поэтому файл звучит так же, как воспроизведение.

## Тестирование

- `npm test`: 33 юнит-теста. Время и тики, сбор событий (циклы паттернов, обрезка нот по клипу, свинг, mute дорожек, разбиение песни на чанки без потерь и дублей), автоматизация, синхронизация delay с темпом, WAV 16/24/32, пики, MIDI и zip туда и обратно, undo/redo со склейкой жестов, кривые параметров, очистка повреждённых проектов.
- Сквозная проверка в Chromium (Playwright): 40 проверок. Транспорт и сигнал на мастере, офлайн-рендер демо-песни без NaN, звук каждого инструмента и эффекта, степ-секвенсор и undo, рисование в Piano Roll, эффекты в микшере, автоматизация из меню ручки, сохранение после перезагрузки, отсутствие ошибок в консоли, мобильная вёрстка (нет горизонтального скролла, тапы по шагам, размеры зон нажатия). Отдельно проверены реальные файлы экспорта (WAV читается утилитой `file`, zip со стемами проходит `unzip -t`) и откат таймера планировщика, когда Web Worker заблокирован.

## Ограничения

- Нет тайм-стретча: аудиоклипы играют в исходной скорости, при смене темпа обрезаются по длине клипа.
- Нет сторонних плагинов (VST/AU): браузер их не поддерживает. Инструменты и эффекты встроенные.
- Нет посылов (sends) между инсертами микшера: все инсерты идут в мастер.
- Задержка записи компенсируется по данным, которые отдаёт браузер. На некоторых Bluetooth-наушниках дубль может немного сдвинуться.
- Экспорт в MP3 не реализован (только WAV): кодер MP3 потребовал бы дополнительной библиотеки.
