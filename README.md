# SOLAR

Static site for Netlify. The whole app is one self-contained page, `index.html`; `netlify.toml` tells Netlify to publish this folder as is, with no build step.

Deploy: in Netlify choose Add new project → Import an existing project → GitHub → `hello-world`, and set **Branch to deploy** to `solar-site`. Every push to this branch redeploys the site.
